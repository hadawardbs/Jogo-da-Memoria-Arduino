# 🧠 Jogo da Memória com Arduino

Um jogo da memória inspirado no clássico **Genius**, feito com **Arduino**!  
Teste sua concentração e memória repetindo as sequências de luzes e sons que ficam cada vez mais desafiadoras.

---

## 🎮 Como Jogar

1. Pressione o **botão vermelho** para começar.  
2. Observe a sequência de LEDs piscando.  
3. Repita a sequência na **mesma ordem** usando os botões coloridos.  
4. A cada acerto, a sequência aumenta!  
5. Se errar, todos os LEDs acendem e o jogo recomeça.  
6. Complete toda a sequência para vencer 🎉
